# 纵横审查

审查者是改动的对手方。diff、PR 描述和作者解释都是待证伪的主张，举证责任在改动一侧；“通过”是证伪失败后剩下的结论，不是默认值。

先认清改动真正改变的对象、事实、状态、负责方、真相源与不变量，不把表层 diff 当问题本身。**纵向**沿一次执行的真实因果链，从触发走到可观察结果与失败恢复；**横向**把同一事实、规则或机制的全部出现处放在一起对账；最后在两向交叉处收敛。两向都按视角答题：每个视角交出一个可核对的具体答案，交不出就是覆盖缺口。

本方法审语义与工程形状是否成立。改动是否符合成文的编码规范、是否实现了需求条目，由 `two-axis-code-review` 审；同一改动走哪一个或两个都走，由上游审查者按项目参数路由。

开始前读取项目参数文件 [`docs/agents/review.md`](../../../docs/agents/review.md)。参数文件应提供：

- 工作地图的工作版本与已发布版本位置；
- 项目探针的位置与命中条件；
- L3 的项目触发条件；
- 端到端旅程的来源；
- 设计稿与页面的依据、走查账号和产品效果确认方；
- 子代理模型；
- 裁决请求格式。

缺失的项按本文与各 reference 的默认值执行。

## 固定范围与基线

固定审查对象、基准版本、证据状态和不审范围。审查对象是 PR 时，由 `pr-review` 固定 current head 并提供原始证据，这里直接消费。

原始证据是审查对象全文或 diff、任务或用户指令、命中的正式规范与接口 / 字段落点，以及测试、CI 或运行证据，缺什么标什么。PR 正文、对话结论、记忆和门禁通过都只是待核材料。

增量复核核对来源审查到当前版本的完整增量，只重判受影响的对象和传播面，继承未受影响且有依据的覆盖。已列 RR 是必须闭环的重点，不是范围上限；修复新增的失败路径和同根遗漏同样纳入。

写验证脚本或探针时调用 Skill 工具：`tdd`，读其 `test-design`；运行或复用验证证据时读其 `verification-execution`。追加运行只针对证据缺口、变化影响或待证伪主张。

## 选择强度

- **L1 局部**：只涉及一个边界清楚的语义对象，不改变负责方、生命周期、不变量或失败 / 恢复边界。固定单一对象锚点审查；发现需要拆对象时升 L2。
- **L2 标准**（默认）：一个复核上下文消费工作地图，分纵向、横向两遍完成。
- **L3 多上下文**：纵向、横向由独立分组完成，主审交叉收敛，按 [分工与回收](references/multi-agent-boundary.md)。触及核心业务链路、访问控制、生产数据或不可逆迁移，或命中参数文件的 L3 触发条件时优先 L3；一个上下文装不下本轮受影响范围时必须 L3。

强度按本轮需要重判的范围选，不机械继承上次阵容。增量复核报告写明原强度、继承范围和本轮强度；本轮 L1 / L2 不冒充重新完成 L3。

## 固定工作地图

L2 / L3 把当前 compact 或 full 工作地图、current head 与原始证据一起固定为审查输入。地图缺失时到参数文件给出的位置恢复（缺省：先找任务临时文件，再找 PR 正文的 `[SEMANTIC-MAP]`），并调用 Skill 工具：`map-semantic-units` 核对；恢复不了的部分报告为覆盖缺口，不用自己推测的决定替代共同合同。

证据显示地图结构错了时返回 `MAP-CHALLENGE`；证据充分的风险立即形成发现，不等地图修订。可以私下拆解质疑，但不另建平行地图。

## 纵向与横向审查

所有强度都按 [纵横审查方法](references/method.md) 执行：先按答题规则推出应有答案，再逐视角交出实际答案，答案记进覆盖索引。派任何审查或取证子代理时读 [分工与回收](references/multi-agent-boundary.md)。

设计稿或改变用户可见页面、流程、反馈、可见性的改动，读 [设计稿与页面取证](references/ui-review.md)，**用真实浏览器走查**，证据并入同一覆盖索引。

## 后置探针

两向答题完成后才加载探针，用它攻击已有结论：

- L2 / L3，或 L1 出现局部补丁、模拟数据、页面派生、接口绕权、旧口径残留时，读 [失败反例](references/gotchas.md)；
- 参数文件给出项目探针时，按它写明的命中条件读取。

探针揭示地图本身遗漏才记 `MAP-CHALLENGE`；普通实现问题直接形成发现。结论仍须落回正式规范、代码和测试证据。

## 收敛与输出

按方法文件的“交叉收敛”形成唯一对外结论，再按 [输出合同](references/output-contracts.md) 输出。审查只报告发现，不顺手修复。

# 输出合同

输出服务于风险判断：只写实际命中的内容，证据有限不写成通过。下面是主审的最终报告；子代理只返回受派范围的中间结果（含它那部分覆盖索引），单向审查标明来源。

## 最终报告

- 审查者、L1 / L2 / L3、对象、范围、不可变基准版本和证据状态；增量复核另写原强度与继承范围。
- 总体结论与本轮最大失败风险。
- 实际涉及的对象、负责方、真相源和不变量；用了工作地图时写形式、绑定版本和挑战结果。
- 覆盖索引：审过的纵切与单元上各视角的答案或缺口，未覆盖片段，当前 / 计划面与退役面，交叉收敛结果。
- 后置探针命中项和未覆盖边界。
- 发现项；无阻断且证据足够时写“未发现阻断”。

L3 另写各分组来源、覆盖与完成状态。任一必需分组未完成时，只输出 `L3 未完成`、失败原文和已完成的中间结果，不给总体结论。

## 覆盖索引

覆盖索引承载答题结果，主审和复核者据此判断每个视角是否真的问过。每条纵切、每个横向单元各一段，先写读实现前推出的应有答案，再写各视角的实际答案：

```text
纵切 <命题：触发 → 可观察结果>
应有：<读实现前推出的要点，如“列表读取访问存储的次数与行数无关”>
- <跳 @ 位置>［重点：不可逆 / 多入口共享 / 随数据放大 / 异于同类］
  必要：<消费者位置>
  数量：<次数表达式>；乘数 <集合>，规模 <多大>，上界 <位置>
  持有：<事务 / 锁 / 连接> 自 <取得的跳> 至 <释放的跳>；期间等待外部 <跳>
  归责：<判断> → <负责的跳>；<他处位置> 是重复 / 假设 / 另一套判据
  断点：事实停在 <位置>；<谁或什么> 能发现；经 <路径> 恢复
- <跳 @ 位置>　必要：<…>　数量：<…>
实证：<运行入口、规模、版本、装配，与正式链路的差异> ｜ 形状已核，量级未证

单元 <事实 / 规则 / 机制>
应有：<…>
唯一：负责方 <位置>；副本 <位置> 靠 <手段> 同步
穷尽：<消费者> 仍成立 / 已修改 / 有缺口（逐个）
对照：同类 <位置> 的做法 <…>；差异的理由 <位置> ｜ 发现
兑现：<承诺> ← <强制它的约束 / 类型 / 测试 / 门禁 / 告警的位置> ｜ 只是文字
新旧：<旧入口、任务、凭据、常量、字段> 仍可运行 / 已终止，依据 <位置>
绕行：<被绕开的包装>：<条件> → <新路径如何保住>（逐条）
```

- 每个视角一行，三者必居其一：答案、使它不成立的事实与位置、缺口（卡在哪、缺什么）。
- 实际答案与应有答案不同的行，标出对应的 RR，或写明它为什么不是发现。
- L1 只有一个锚点时，纵切与单元各写一段。版式可以压缩，行不能省。

**验收**：主审收分组结果、复核者读主审报告，都先核覆盖索引：抽查位置能否打开、次数表达式与持有范围是否与代码对得上。缺行或“已检查”式的答案按缺口处理，结论随之下调。

## 发现项

处置（`FIX_CURRENT` / `TRACK_ISSUE` / `DECISION_REQUIRED` / `INSUFFICIENT_EVIDENCE`）按 `task-closure` 的 `finding-disposition`，有候选发现时集中调用一次；严重程度、证据等级与 RR 规则按 `pr-review` 的 `structured-review-output`。需要开发代理复核或落地的成立问题（含 `TRACK_ISSUE`）都分配活动 RR，结果返回前不判 `PASS`。纵横审查在每条 RR 上另写：

- **地图落点**：对象 / 关键边 / 未映射表面；
- **根因组**：同根 RR 相邻排列，修复与复核按根因组进行；
- **来源**：纵向 / 横向 / 交叉，以及问出它的视角；
- **证据状态**：证据充分 / 有限 / 缺少。

RECHECK 关闭根因组时写明地图绑定、被审 head、复用的覆盖索引，以及是否还有未处置的当前命中；有就不通过。

有阻断 / 严重发现时注明“建议回补样本”或“已有样本覆盖”，样本按 [失败反例](gotchas.md) 的回补规则处理。

## 地图挑战

只在证据与工作地图冲突时输出：

```md
- Map binding: <compact / full + commit SHA>
- Map challenge: MAP-CHALLENGE
- Target: <对象 / 关键边 / 未映射表面>
- Claim / evidence / impact / smallest delta: <...>
```

`MAP-CHALLENGE` 本身不分配 RR 或严重程度。地图维护者修订同一地图；一次定向复核后仍未决时，审查保持 `MAP-CHALLENGE` 并停止依赖工作。

## 交接

发现项与覆盖索引一并返回 `pr-review`，评论格式与发布由它负责；覆盖索引放进评论末尾的折叠段，供复核者核对。需要用户裁决时按参数文件的裁决请求格式输出完整裁决请求（缺省：需要决定什么、已知事实与证据缺口、建议与理由、选择后的影响）。

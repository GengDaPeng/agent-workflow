# 控制指令

先在任务入口记录决定，再通知执行者；紧急停止可先发。任务入口按参数文件；新协作缺入口时先准备，不在消息里另写任务合同。常规开发与审查交接不逐轮等主控批准。

```text
<接取并执行｜审查｜调整｜暂停｜恢复｜终止>：<任务入口>
```

只按实际缺的项追加：

| 条件 | 追加行 |
|---|---|
| 首次建立协作 | `协作：使用 $agent-message；汇报对象：<通道与地址>。` |
| 新指定主审 | `审查对象：<成果入口>；开发：<通道与地址>。` |
| 开发缺主审联系人 | `审查：<通道与地址>；候选就绪后直接交接。` |
| 缺开发同伴联系人 | `同伴：<职责、通道与地址>。` |
| 改变原安排 | `变更：<改变的一项安排>；依据：<决定入口>。` |
| 暂停 | `恢复条件：<条件或责任方>。` |
| 下一动作依赖未确认的交接事实 | `请确认：<停写、结束取证或资源释放事实>。` |

只有明确改由主审报告时，向双方发：

```text
通过后：主审通知指定汇报对象，开发等待；替代默认交付出口。
```

既定出口不重复通知。收到控制指令后的项目动作按主控委托处理；需要上级决定时发裁决请求。
